# BurzaRadar 1.0

Niezależna aplikacja Android do szybkiego podglądu bieżącej sytuacji burzowej i pogodowej.

## Funkcje
- dynamiczna mapa burzowa Sieci Obserwatorów Burz,
- radar/opady IMGW-PIB,
- ostrzeżenia IMGW-PIB,
- mapa wyładowań Blitzortung,
- obsługa lokalizacji w mapach WWW,
- ręczne odświeżanie,
- stała nawigacja na dole ekranu.

## Źródła
Aplikacja nie podszywa się pod Monitor Burz i nie używa prywatnego API. Wyświetla publicznie dostępne serwisy internetowe z oznaczeniem źródła.

- https://obserwatorzy.info/mapapp.html
- https://meteo.imgw.pl/dyn/
- https://map.blitzortung.org/
